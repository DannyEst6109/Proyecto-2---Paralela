# Escudo de la carátula

`escudo_uvg.png` se extrajo de la primera página de `annotated-Proyecto%20-%20Entrega%202.pdf`, usado como referencia de carátula.

Se reutiliza en la carátula del Proyecto 02 junto con la composición centrada, tipografía serif y orientación vertical de la referencia. Los integrantes, el título y la fecha corresponden a la entrega actual.
